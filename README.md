# VersePC2-simple-home

基于 VersePC2 的主页插件 – 下滑展开「简单主页」，集成快捷网站、内存优化、清理游戏垃圾三大功能。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| **下滑展开** | 仅在「主页」且滚动到顶部时，继续向下滚动（滚轮 / 触摸板 / 触摸），主内容区整体向上平移 350ms（ease-out），露出下方贴底的「简单主页」面板。类似网页滚到顶部继续下拉露出新内容。 |
| **上滑收回** | 向上滚动，主内容回落原位，面板同步下移隐藏。 |
| **多种关闭方式** | 上滑、点击面板右上角「✕」、点击半透明遮罩、按 `Esc`、或切换到其它页面。 |
| **备用唤出** | `Ctrl+Alt+H` 快捷键（手势开关关闭时也生效）。 |
| **默认开启** | 下滑展开每次启动都默认开启（忽略历史关闭值）；面板底部开关仅本次会话有效，重启恢复开启。也可用 `VersePC.SimpleHome.setGesture(true)` 即时开启。 |
| **快捷网站** | 面板内的网站清单直接从启动器「工具箱」页面模板解析，点击在系统默认浏览器打开。 |
| **释放内存** | 复用启动器「设置 → 其他」的内存优化能力（`doMemoryOptimize()`）。 |
| **清理游戏垃圾** | 复用启动器垃圾扫描与一键清理（`cleanupScan()` → `cleanupRun()`）。 |
| **双语支持** | 按 `navigator.language` 自动切换中 / 英文，可在面板底部手动覆盖。 |
| **样式隔离** | 所有 UI 渲染在 Shadow DOM 内，仅继承启动器 CSS 变量以保持一致观感。 |
| **零侵入** | 不拦截、不阻止任何原有事件（滚轮与触摸监听均为 passive 且不调用 preventDefault），不会影响启动器原有功能。 |
