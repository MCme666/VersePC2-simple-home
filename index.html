Simple Home · 简单主页

下滑打开快捷网站 · 一键内存优化 · 清理游戏垃圾

插件信息

插件 IDsimple-home 显示名称简单主页 版本1.0.0 作者MCme 分类function（功能） 开源协议GPL v3

功能说明

  • 下滑展开：仅在「主页」且页面滚动到顶部时，继续向下滚动（滚轮 / 触摸板 / 触摸），主内容区整体向上平移 350ms（ease-out），露出下方贴底的「简单主页」面板——类似网页滚到顶部继续下拉露出新内容。
  • 上滑收回：向上滚动，主内容回落原位，面板同步下移隐藏。
  • 关闭方式：上滑、点击面板右上角「✕」、点击半透明遮罩、按 Esc、或切换到其它页面。
  • 备用唤出：Ctrl+Alt+H；手势开关关闭时也生效。
  • 默认开启：下滑展开每次启动都默认开启（忽略历史关闭值）；面板底部开关仅本次会话有效，重启恢复开启。也可用 VersePC.SimpleHome.setGesture(true) 即时开启。
  • 快捷网站：面板内的网站清单直接从启动器「工具箱」页面模板解析，点击在系统默认浏览器打开。
  • 释放内存：复用启动器「设置 → 其他」的内存优化能力（doMemoryOptimize()）。
  • 清理游戏垃圾：复用启动器垃圾扫描与一键清理（cleanupScan() → cleanupRun()）。
  • 双语：按 navigator.language 自动切换中 / 英文，可在面板底部手动覆盖。
  • 样式隔离：所有 UI 渲染在 Shadow DOM 内，仅继承启动器 CSS 变量以保持一致观感。
插件不拦截、不阻止任何原有事件（滚轮与触摸监听均为 passive 且不调用 preventDefault），不会影响启动器原有功能。

安装与自检

  • 把 plugin.json、main.js、style.css、index.html 所在目录整体压缩为 simple-home.zip（plugin.json 需位于包内有效根目录）。
  • 在启动器「插件 → 已安装」安装该 zip，安装成功后回到「主页」向下滚动即可展开面板。
  • 若侧边栏按钮 / 面板未出现，重启启动器触发运行时重扫；启动器「日志」中可查看 [plugin-runtime] 相关输出。
  • 网站图标来自在线 favicon 服务，离线时自动回退为站点首字母，不影响点击打开。
